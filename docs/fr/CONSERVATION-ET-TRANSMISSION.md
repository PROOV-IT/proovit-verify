# Conservation et transmission d’une archive

**Public :** entreprises, avocats, commissaires de justice, experts et services judiciaires.

## Conservation recommandée

Conserver l’archive originale sans modification, son SHA-256, le code d’accès transmis séparément, le rapport produit et la version exacte du vérificateur. Lorsque le contrôle blockchain est utilisé, conserver également les paramètres publics et le rapport de connexion.

## Transmission recommandée

Transmettre l’archive, son empreinte SHA-256, le code d’accès par un canal distinct et le rapport de vérification. Indiquer la date du contrôle, la version du logiciel et l’accès réseau utilisé pour les contrôles externes.

## Chaîne de conservation

Documenter les détenteurs successifs, les copies réalisées, les supports utilisés et les opérations effectuées. Une copie de travail ne doit pas remplacer l’archive originale.
