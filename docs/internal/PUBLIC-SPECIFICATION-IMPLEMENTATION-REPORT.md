# Public Specification Implementation Report

## Delivered in v0.2.9

- Updated README and protocol entry point.
- Added third-party, trust-model and compatibility documentation.
- Documented archive V1, manifest V3, Web timeline behavior, multimedia semantics and blockchain events.
- Added a synthetic canonical JSON vector generated by `scripts/validate_docs.py`.
- Added manual CI validation for the documentation vector and Python syntax.
- Added a gap analysis that records implementation references and unresolved ambiguities.

## Verified against code

The documented canonical JSON behavior, manifest self-hashing exclusions, Ed25519 signing input, timeline event hash payload, `ProofStoredV3`/`FileAddedV3` event signatures and legacy compatibility statements were checked against the public verifier and the backend producer code.

## Remaining gaps

The repository does not yet contain complete synthetic vectors for Ed25519, timeline, `evidence_root_hash`, `filesRoot` and blockchain event decoding. A complete field-by-field Web acquisition provenance specification also requires a further inventory of the producer. No JSON Schemas were added because the current producer has optional and legacy shapes that are not yet stable enough to express without inventing constraints.

These gaps are intentional and are not presented as implemented protocol guarantees.
