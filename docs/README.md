# Documentation des preuves PROOV-IT

PROOV-IT publie le format de ses archives de preuve et les procédures de contrôle associées. Une archive portable rassemble les fichiers, les inventaires, les manifestes et les références techniques nécessaires à son examen. `proovit-verify` permet de recalculer localement les empreintes, la canonicalisation du manifest et sa signature ; les contrôles blockchain peuvent être réalisés directement auprès d’un réseau public. Les spécifications sont publiées afin qu’un tiers puisse auditer ou réimplémenter les contrôles indépendamment de la plateforme PROOV-IT.

Les documents français sont destinés aux utilisateurs, professionnels du droit, experts et décideurs. Les spécifications techniques sont en anglais afin de rester directement exploitables par les implémentations indépendantes. Les fichiers JSON de test constituent les exemples machine-readable publiés avec le dépôt.

La vérification technique ne constitue pas une appréciation de recevabilité, d’imputabilité ou de force probante. Ces appréciations relèvent du contexte du dossier et des autorités compétentes.
