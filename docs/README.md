# PROOV-IT Evidence Documentation

Documentation du format d’archive PROOV-IT et des contrôles réalisables avec le vérificateur open source.

## Choisir son parcours

- **Comprendre une preuve** : [COMPRENDRE-UNE-PREUVE](fr/COMPRENDRE-UNE-PREUVE.md)
- **Vérifier une archive** : [GUIDE-VERIFICATION](fr/GUIDE-VERIFICATION.md)
- **Lire un rapport** : [INTERPRETER-UN-RAPPORT](fr/INTERPRETER-UN-RAPPORT.md)
- **Conserver et transmettre** : [CONSERVATION-ET-TRANSMISSION](fr/CONSERVATION-ET-TRANSMISSION.md)
- **Expertise numérique** : [MODELE-DE-CONFIANCE](expert/MODELE-DE-CONFIANCE.md), [ARCHITECTURE-DE-VERIFICATION](expert/ARCHITECTURE-DE-VERIFICATION.md), [PROVENANCE-DES-DONNEES](expert/PROVENANCE-DES-DONNEES.md)
- **Développement et réimplémentation** : [spécifications](specs/PROOVIT-EVIDENCE-PROTOCOL.md), [vecteurs de test](test-vectors/), [schémas](../schemas/)

Les documents français sont destinés aux utilisateurs, professionnels du droit, experts et décideurs. Les spécifications techniques sont en anglais afin de rester directement exploitables par les implémentations indépendantes.

La vérification technique ne constitue pas une appréciation de recevabilité, d’imputabilité ou de force probante. Ces appréciations relèvent du contexte du dossier et des autorités compétentes.
